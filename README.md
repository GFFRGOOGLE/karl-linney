# Карл Линней — отец систематики

Проект по биологии для 5 класса. Презентация о Карле Линнее в трёх вариантах оформления и доклад для выступления.

## Файлы

- `index.html` — сайт с онлайн-просмотром и скачиванием
- `prezentacii/Karl-Linney-yarkaya.pptx` — яркая версия (6 слайдов)
- `prezentacii/Karl-Linney-temnaya.pptx` — тёмная версия (6 слайдов)
- `prezentacii/Karl-Linney-chistaya.pptx` — чистая белая версия (6 слайдов)
- `prezentacii/Doklad-po-slajdam-karl-linney.docx` — доклад по слайдам
- `prezentacii/Doklad-karl-linney.docx` — текст выступления

## Онлайн-просмотр

Сайт доступен через GitHub Pages: `https://GFFRGOOGLE.github.io/karl-linney/`

Презентации также можно открыть онлайн через Google Docs viewer по кнопке на сайте.
